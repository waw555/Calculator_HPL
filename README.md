# Calculator HPL

PHP-приложение для расчёта изделий из HPL: сантехнические кабины, столешницы, раскрой панелей и подсистема.

## Конфигурация

Подключение к MySQL читается из переменных окружения с безопасными значениями по умолчанию для локального Docker-окружения:

| Переменная | Значение по умолчанию |
| --- | --- |
| `DB_HOST` | `db` |
| `DB_NAME` | `hpl` |
| `DB_USER` | `hpl` |
| `DB_PASS` | `hplpass` |
| `DB_CHARSET` | `utf8mb4` |

Для production задавайте эти значения на уровне окружения веб-сервера или контейнера и не храните реальные пароли в репозитории.

## Миграции

Схему базы можно подготовить отдельным CLI-скриптом, чтобы не полагаться на создание таблиц во время HTTP-запросов:

```bash
php scripts/migrate.php
```

## Проверки

Минимальная проверка синтаксиса всех PHP-файлов:

```bash
for f in $(rg --files -g '*.php'); do php -l "$f"; done
```

## Безопасность

- Сессии создаются с `HttpOnly` cookie и `SameSite=Lax`.
- POST-запросы проходят базовую CSRF-проверку по токену или same-site/same-origin заголовкам браузера.
- Старые MD5-пароли автоматически перехэшируются через `password_hash` после успешного входа.
- Загруженные файлы получают права `0644`, а каталоги внутри `uploads` — `0777`,
  чтобы загрузка продолжала работать после обновления сайта другим системным пользователем.
